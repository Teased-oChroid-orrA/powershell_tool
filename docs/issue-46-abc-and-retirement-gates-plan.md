Status: research and execution plan, 2026-10-23. This covers the two named ABC files and the broad exit gates after the separate boss-rim, tilted-hole and Windows-runtime plans. It changes no implementation or approval state.

`00006600` stops in graded surface sampling, before PLC. On B-spline face #379, bound #1066, segment 156, adjacent spline-edge samples become about 6.8e-10 mm apart while their edge-to-face projection residual is about 2.7e-6 mm, so both map to one chart point. `AnalyticModel::graded` now correctly reports non-convergence when splits are requested but no samples are inserted (Phase 133). A generic spacing filter already degraded quality or bounded runtime. `00007062` now grades and samples a 48-face shell of 110,215 vertices / 220,430 triangles, volume 15,642.890414806012 mm³, minimum shell angle 0.0316062545°; Phase 129 used a zero-second PLC timeout, which Phase 130 made effective before Delaunay initialization. No completed conforming mesh or solve has been shown. The 18° registry input gate remains unchanged. [CGAL's 3D meshing manual](https://doc.cgal.org/latest/Mesh_3/index.html) describes feature protection and angle-sensitive refinement; it supports keeping an explicit small-feature refusal until bounded termination and fidelity are measured, not relaxing this project's gate by inference.

Keep `GradeReport::converged` truthful. Do not use `ABC_TOL_MM` to make a failure disappear.

Determine whether the source edge and face disagree geometrically, whether projections choose inconsistent branches, or whether a demanded split is smaller than the independently bounded projection error. The decision is evidence-based: repair the responsible source association/projection if it is wrong; if the source is genuinely inconsistent at that scale, return a precise bounded refusal. Add a stalled-grading regression so a split request with no insertion cannot be reported as convergence.
4. Run the local ABC file end to end through grade, sampled shell, PLC quality gate and static solve under explicit work/time limits. If it still refuses, record the next exact stage and do not mark it solved. Run `cargo test -p solid-kernel --no-default-features --locked --offline -j1` plus OCCT-enabled source comparisons for the touched surface path.

## Retirement gate, 2026-11-01 (Phase 165)

Status: proposed with Phase 165 and adopted by the owner on 2026-11-01 (decisions below). It changes no implementation or approval state, and `occt_retirement_approved` stays false: setting it still needs a separate explicit owner approval after every item passes. [Phase 165](issue-46-phase-165.md) ran the production path over 35 licensed real-CAD files (33 NIST PMI models, 2 OpenCascade samples). Native refused 33 at STEP import (21 on placement mapping); OCCT read all 35 but meshed only 3 at the import's own default size. The ABC pair is parked as known refusals by owner decision and does not count toward retirement.

The gate, per model and per stage, so that a refusal is attributed rather than averaged away:

1. **Built-in parity.** The 19-model same-STEP table and its asserted comparison, as in Track C step 1: every row that OCCT passes, native passes; NEMA17 stays a documented joint failure by owner request.
2. **Real-CAD corpus, measured by stage.** On a fixed, licensed corpus (Phase 165's 35 files, extended only with files of verified usage rights): (a) import: the share of files native reads, against the files OCCT reads; (b) for files both paths read, at a size both meshers accept: native meshes, passes the default gate wherever OCCT passes, and matches OCCT's benchmark within the asserted comparison's factors (compliance 5 %, energy 6 %, reaction 4 %, displacement 15 %, counts 15 %, times within 3x). For (a), native must read every file OCCT reads (owner decision 1).
3. **Target platform.** Feature-off STEP import, mesh and solve on Windows (`issue-46-windows-runtime-plan.md`), with the release contract unchanged. [Phase 167](issue-46-phase-167.md) shows this for the 14 built-in native models with `cargo test` on hosted Windows; the packaged offline clean-machine acceptance of `app-tui.exe` remains.
4. **Editor operations.** A native/OCCT capability matrix of every editor operation; every operation native does not support refuses explicitly with the reason, never silently falls back.
5. **Fallback.** Until a model passes 1-4 natively, it keeps a reviewed per-model OCCT route. That state is an intermediate milestone, not retirement (owner decision 2).
6. **Completion checklist.** P0 and P1 items of `issue-46-completion-checklist.md` remain prerequisites; P2 and P3 items do not (owner decision 3).

Owner decisions, 2026-11-01:

1. **Corpus acceptance rate:** native must import and mesh every licensed-corpus file that OpenCascade reads. Files OpenCascade also refuses stay explicit refusals on both paths.
2. **Native by default with per-model OCCT fallback does not count as retirement.** Retirement means OpenCascade is removed from the build; native-by-default with a bundled fallback is an intermediate milestone.
3. **P2/P3 checklist items are roadmap work**, not retirement prerequisites. P0/P1 remain prerequisites.
4. **Thin-walled large parts keep refusing.** When the import's default size (wall / 3) asks for more elements than `solid_mesh` accepts, the fast, explicit refusal that tells the user to increase the size stays. The default is not coarsened to a size that does not resolve the wall (a floor at the accepted estimate was measured and dropped in Phase 165).

## Stop conditions

Keep a refusal and document it if a proposed repair changes source topology without proof, makes distinct edge samples coincide, worsens chart/shell fidelity, exceeds bounded work, skips a 0.0316° feature without preserving geometry, admits a mesh that fails the default solver gate, regresses any previously passing model, or relies on a quality threshold/tolerance increase. A partial ABC improvement is evidence for that file and stage only.
