# Issue 46: ABC failures and remaining retirement gates plan

Status: research and execution plan, 2026-10-23. This covers the two named ABC files and the broad exit gates after the separate boss-rim, tilted-hole and Windows-runtime plans. It changes no implementation or approval state.

## Current evidence and boundaries

`docs/issue-46-current.json` places Phase 136 on `main`, with OCCT still the production backend and `occt_retirement_approved: false`. The ABC survey is diagnostic: the isolated 300-file run with opt-in PLC quality refinement returned 149 conforming meshes, 30 solver-gate passes and 30 static solves, with 14 timeouts. It does not use the application's `fea-problem::solid_mesh` production path and does not establish OCCT/native parity. ABC model redistribution rights are not established; keep the two source STEP files outside the repository, and commit only independently created minimal synthetic fixtures.

`00006600` stops in graded surface sampling, before PLC. On B-spline face #379, bound #1066, segment 156, adjacent spline-edge samples become about 6.8e-10 mm apart while their edge-to-face projection residual is about 2.7e-6 mm, so both map to one chart point. `AnalyticModel::graded` now correctly reports non-convergence when splits are requested but no samples are inserted (Phase 133). A generic spacing filter already degraded quality or bounded runtime. `00007062` now grades and samples a 48-face shell of 110,215 vertices / 220,430 triangles, volume 15,642.890414806012 mm³, minimum shell angle 0.0316062545°; Phase 129 used a zero-second PLC timeout, which Phase 130 made effective before Delaunay initialization. No completed conforming mesh or solve has been shown. The 18° registry input gate remains unchanged. [CGAL's 3D meshing manual](https://doc.cgal.org/latest/Mesh_3/index.html) describes feature protection and angle-sensitive refinement; it supports keeping an explicit small-feature refusal until bounded termination and fidelity are measured, not relaxing this project's gate by inference.

## Track A — `00006600`: shared-edge chart agreement

Reproduce the Phase 129 refusal with the local file and bounded `abc-corpus` invocation; record exact commit, stage, face/bound/segment, source edge parameter and world-space spacing, each neighboring face's projected chart coordinates/residuals, and the sample count per `chart_grade` round. Keep `GradeReport::converged` truthful. Do not use `ABC_TOL_MM` to make a failure disappear.
2. Trace `chart_mesh::boundary_splits` -> `chart_grade::graded` -> `AnalyticModel::insert_edge_splits` -> `SplineSurface::chart_loop` at the first collision. Determine whether the source edge and face disagree geometrically, whether projections choose inconsistent branches, or whether a demanded split is smaller than the independently bounded projection error. The decision is evidence-based: repair the responsible source association/projection if it is wrong; if the source is genuinely inconsistent at that scale, return a precise bounded refusal. Never merge two distinct topological edge samples solely by an arbitrary distance threshold.
3. Build a redistributable two-face rational B-spline STEP regression with a shared spline edge that reproduces the diagnosed mechanism. Assert original endpoint/edge identity, finite trims, face-chart orientation, no duplicate chart boundary point, positive sampled shell and bounded world-space deviation; include a negative case whose source discrepancy must still refuse. Add a stalled-grading regression so a split request with no insertion cannot be reported as convergence.
4. Run the local ABC file end to end through grade, sampled shell, PLC quality gate and static solve under explicit work/time limits. If it still refuses, record the next exact stage and do not mark it solved. Run `cargo test -p solid-kernel --no-default-features --locked --offline -j1` plus OCCT-enabled source comparisons for the touched surface path.

## Track B — `00007062`: PLC recovery and solver usability

1. Replay the same graded 48-face shell with a nonzero, recorded timeout and isolated machine load. Record PLC phase, progress, memory, inserted Steiner points, recovered facets/segments, fallback use, radius-edge distribution, minimum angle, final volume discrepancy and whether the result is conforming. Retain the early cancellation and budget checks; a zero-second diagnostic proves cancellation only.
2. Reduce the first actual PLC refusal or timeout to a small closed shell with the same feature geometry, if feasible. Identify whether it is an input-angle limitation, encroachment cascade, incorrect protected/unprotected fallback, a recoverable topology error, or pure cost. Fix only a demonstrated algorithmic defect in `solid-kernel/src/plc_conform.rs` or its input preparation; add a synthetic regression for manifoldness, exact facet/segment recovery, bounded termination and cancellation. A genuine 0.0316° feature-size limit must remain a refusal unless a different certified strategy is shown. [Shewchuk's small-angle meshing research](https://www.cs.cmu.edu/~quake/papers.html) explains why small input angles need special treatment; it is a design reference, not proof that the current engine can mesh this shell.
3. If conformity succeeds, call `Conforming::to_solver_mesh` with unchanged `QualityThresholds::default()` and run the harness's static benchmark. Record scaled Jacobian, edge ratio, size jump, unresolved bad cells, equilibrium, element/DOF count, mesh and solve time. Conformity alone is not completion. Compare against OCCT on the same model and sizing if redistribution/local access permits, with each result's provenance explicit.
4. Re-run the isolated 300-file diagnostic only after a retained fix, with the same file set, options and process budgets as the baseline: `--foreign --graded --steiner 200000 --conform-timeout 100 --timeout 150 --merge --quality --refine --jobs 4`. Record per-file transitions and regressions, not merely the overall pass count; separate runtime variability from a code effect with repeated focused runs.

## Stop conditions

Keep a refusal and document it if a proposed repair changes source topology without proof, makes distinct edge samples coincide, worsens chart/shell fidelity, exceeds bounded work, skips a 0.0316° feature without preserving geometry, admits a mesh that fails the default solver gate, regresses any previously passing model, or relies on a quality threshold/tolerance increase. A partial ABC improvement is evidence for that file and stage only.
