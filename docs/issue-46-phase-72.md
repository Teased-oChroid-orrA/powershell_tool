# Issue 46 — Phase 72: mesh motion subsystem (#59)

`fea_core::meshing::motion::move_mesh(mesh, prescribed, options)` relocates the nodes of any mesh without changing its connectivity so that the prescribed nodes follow given total displacements. It is the geometric motion subsystem of the epic's section 22 (boundary displacement, geometry-constrained nodes via zero-displacement prescriptions, interior displacement solution, quality monitoring, inversion prevention, distortion detection, rollback, hand-over to remeshing). It is **not** an ALE formulation: there is no mesh velocity, no convective term and no coupling to governing equations (section 23); structural Lagrangian motion with this subsystem stays a separate capability.

Method: the interior displacement solves a pseudo-elastic problem on the mesh itself with each element its own block and Young's modulus `(mean size / element size)^exponent` (default 2), so small elements next to a moving wall are stiff and take little of the motion; prescribed nodes carry the displacement, all others are free. The motion is applied in sub-steps (default 4, re-solved on the updated mesh). After each step the mesh must have no inverted element, a scaled Jacobian above `min_scaled_jacobian` and an edge ratio below the ceiling; a failing step is rolled back and retried with half the increment, and when the increment drops below `min_increment` (or `max_retries` is exceeded) the motion stops at the last valid mesh and returns `Outcome::NeedsRemesh { applied_fraction, reason }`. The input mesh must itself pass the thresholds, bad input (no prescribed node, out-of-range node, non-finite displacement, zero steps) is refused, and the report carries the applied fraction, steps, rollbacks, quality before/after, the largest node displacement and an equilibrium figure (largest free-dof reaction relative to the largest prescribed-dof reaction).

Evidence (macOS arm64): 4 tests. A 4x4x4 Hex8 box with its top wall moved by -0.3 completes, puts the wall at exactly 0.7, keeps the connectivity identical and the minimum scaled Jacobian above 0.9, with a free-reaction ratio below 1e-8. Pushing a 3x3x3 box's top 1.5 through its bottom stops at a valid intermediate mesh (0 inverted, floor respected, at least one rollback) with `NeedsRemesh`. On a mesh graded towards the moving wall (3x3x8, exponent 2.5) with the wall moved by -0.5, the size-stiffened motion keeps a minimum scaled Jacobian of 0.481 against 0.229 for a uniform pseudo-solid (edge ratio 76.6 against 89.2). Bad input is refused. Full `fea-core` suite and clippy: see the PR.

Limits (not fixed): no tangential sliding of prescribed boundary nodes along the geometry (a node is fully prescribed or free), so geometry-constrained motion beyond fixing nodes needs the caller to compute the projected target; the pseudo-solid is linear per step, not an optimisation-based displacement; no ALE, mesh velocity or transport; the state/history transfer after remeshing is the existing `adaptivity::nonlinear::transfer_history`, which this subsystem does not call; only the geometry-level quality gates, not solver-aware ones; no Windows or hosted-CI evidence.
