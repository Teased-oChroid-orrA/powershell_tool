The bad tet meets faces `face3` and `face7`. Native `face7` has 1,422 triangles versus OCCT's 64; the other six faces have equal counts, and the two ellipse rims each have 33 samples. The extra triangles arise in the face's interior chart refinement. Because the denser face touches the bad tet but has not been shown to cause it, no tessellation or repair limit was changed.
- A focused box-with-boss comparison reproduced OCCT minimum scaled Jacobian 0.091 with 3 sub-gate tets and native 0.096 with 5. Testing the suspected repair stagnation rule by allowing 100 rounds changed neither result; OCCT mesh time rose from about 4.3 to 39 seconds. The experiment was reverted. A diagnostic retry's successful operation did not cure the bad tet, so the count-based stop is not the demonstrated cause.

Grading can ask for splits arbitrarily close to an edge endpoint, while the edge and surface projections differ by more than those tiny sample gaps. A general spacing filter had already failed quality or bounded-runtime checks in [Phase 127](issue-46-phase-127.md). No topology-preserving split rule or redistributable synthetic regression has been proved, so the overlap validator remains unchanged.
