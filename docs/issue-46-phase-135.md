# Phase 135 — browse to open a model file (2026-10-22)

Epic #46, continuing [Phase 134](issue-46-phase-134.md). The native solid editor's File > Open and Ctrl/Cmd+O now show a directory browser in the inspector. A folder click enters it, `..` goes to its parent, and a file click uses the existing `open_path` path. The browser lists directories and `.json`, `.msh`, `.inp`, `.step`, and `.stp` files. The path prompt remains for direct entry; Esc cancels. The terminal FEA Workbench's `o` prompt now offers a JSON directory browser with Tab; Enter opens the selected file through the existing read and JSON validation flow. Esc cancels, and Tab returns to path entry.

Both browser paths use the filesystem only and add no dependency or runtime network requirement. Opening a bad file preserves the current model. The native browser test covers folder navigation, cancellation, a saved `.fea.json`, an invalid JSON file, and a generated native STEP cube. The terminal test covers browsing, cancellation, typed-path retention, a valid project, and an invalid project.

Qualification on macOS arm64: `cargo test -p app-tui --locked --offline -j1 open_prompt_browses_and_keeps_typed_path` and `cargo test -p app-tui --locked --offline -j1 open_browser_navigates_and_uses_existing_open_validation` passed. The full `cargo test -p app-tui --locked --offline -j1` passed 1,188 unit tests (22 ignored) and 38 rendering integration tests. The terminal Workbench was also run in a real PTY; the first run exposed a stale prompt outline outside the browser, which was fixed by clearing that rectangle before drawing the browser. A final real-PTY run after the fix is pending. The native window could not be inspected through the macOS app inventory in this environment; its inspector card and file-selection behavior are covered by the focused test, but a visible native-window screenshot remains open.

This phase changes file selection, not OCCT retirement criteria. `occt_retirement_approved` remains false. Boss-rim scaled-Jacobian quality, native tilted-hole quality, ABC grading, Windows runtime mesh/solve, and broad production parity remain open.

## Boss-rim follow-up probe

A temporary connected synthetic body used a plate `[0,0,0]`–`[12,4,1]` and a radius-1.2 boss centered at `[6,2]` extending to `z=4`, with exact signed distance and face hits (`base=0.6`, `boundary_size=0.25`). It reproduced the shared defect: 179,640 tets, 27 below the 0.1 scaled-Jacobian gate, minimum 0.0190566693. Boundary repair reduced 2,371 sub-gate tets to 27 after 19 rounds but refused 523 remaining candidate collapses. Trace categories included orientation (13,740), quality (10,008), link (2,504), and surface fidelity (1,943) refusals across candidates and rounds. Short edges of 0.005–0.010 mm persist at the rim. This supports Phase 134's topology diagnosis; it does not justify relaxing a guard or establish a safe fix. Temporary test and trace code were removed. The probe took about 25 seconds and is not part of the regular suite.

The tilted-hole candidate was also reviewed. Axial separation of opposite-rim chart samples alone cannot prove that skipping their chord is safe: an oblique neighboring face may intersect it. No chart rule or quality claim was retained.
