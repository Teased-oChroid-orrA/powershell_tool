# Thread Workbench: Unified axial strength and damage

The native Thread Workbench compares one changed characteristic with an undamaged baseline. It supports direct tapped threads, helical-coil STI tapped holes, and solid key-locking inserts. Inputs use inches, TPI, ksi and lbf. The saved case is JSON; the text report records both capacities and missing evidence.

## Sources and equations

- [ASME B1.1-2003](https://law.resource.org/pub/us/cfr/ibr/inc/asme/asme.b01.01.2003.pdf), Unified 60-degree profile: basic pitch diameter `d - 0.649519P`, internal minor diameter `d - 1.082532P`, and external basic root diameter `d - 1.226869P`. These are basic reference dimensions, not class 2A/2B or 3A/3B limits.
- [NASA NSTS 08307A, Appendix A](https://files.engineering.com/files/1e29284f-4130-4184-9997-17ed698ba73b/NSTS-08307.pdf), Unified tensile stress area `π/4(d - 0.9743P)^2`; 1/4-28 evaluates to approximately `0.0364 in²`. Bolt tensile capability is area times user-supplied tensile strength. A measured root reduction scales area by the ratio of damaged to basic root-section areas.
- [FED-STD-H28/2A](https://quicksearch.dla.mil/Transient/D0A44A8FD8844E7C9515CE8F1B4F0443.pdf), section 70.2: external stripping area `πnL D₁[1/(2n) + 0.57735(d₂ - D₁)]` and internal stripping area `πnL d[1/(2n) + 0.57735(d - D₂)]`. The Workbench uses the entered mating diameters and multiplies each area by the corresponding material shear strength. Its basic-dimension screen does not apply thread-class allowance or tolerance limits.
- [Stanley Heli-Coil catalog HC-2000, Table VII](https://usgage.com/wp-content/uploads/2023/08/Heli-Coil_Catalog_HC2000_Rev12.pdf): STI tapped-hole pitch and minor diameter ranges for the supported UNC/UNF sizes. The bolt's nominal TPI does **not** describe the larger STI tapped thread. Coil wire transfer, tang, parent pull-out, and installation effects require a manufacturer rating for the matched size, insert length, parent material and installation.
- [KEENSERTS Series KN catalog](https://www.hfsindustrial.com/pub/media/resources/images/image/4/-/4-e-inserts_9-2022.pdf): the default thin-wall 1/4-28 internal / 3/8-16 external insert is a catalog pairing. Other pairings may be entered. The external thread can have a modified root. Key retention, insert body strength, and full assembly pull-out require a sourced manufacturer rating.

## Scope and evidence gates

For a directly tapped thread, the lowest of bolt tension, bolt external stripping and parent internal stripping is shown. For a helical coil, bolt tension and a matched assembly rating are shown only when STI hole measurements fall inside a sourced catalog range. For a Keensert, insert internal thread shear is modeled, while unadjusted external and parent thread shear appear only as gross-area upper bounds because key interruptions are unknown; the key/body/assembly path remains unrated until the user enters a manufacturer rating and source. If any required path lacks evidence, the Workbench shows no governing assembly capacity. Every geometry or material edit invalidates an insert rating for the proposed case.

The default strengths and 3,000 lbf load are illustrative inputs, not material allowables. The analysis is axial and static. It does not model preload, torsion, combined stress, transverse load, fatigue, temperature, corrosion, tolerance stack or safety factors. A measured diameter is a full-circumference effective diameter; localized flank damage needs inspection or a separate qualified analysis. A manufacturer rating must match the actual insert, parent material, length and installation.

## Inch insert installation catalog and material selection

`thread_capability.rs` holds 44 inch UNC/UNF Heli-Coil STI entries. Stanley HC-2000 Table VII (PDF p. 7) supplies class 2B tapped-hole pitch and minor limits. The Heli-Coil Bulletin 2003 Table V (PDF p. 16) supplies separate suggested STI pilot-drill diameters for aluminum and for steel, magnesium or plastic. The 5/8-11 nominal in HC-2000 prints `.65250`; the catalog key uses the correct `5/8 = .6250`. The 3/4-16 tapping-depth print also has an apparent decimal error; no tapping-depth value from that row is imported. Pilot drills are suggestions, not a substitute for checking the minor diameter after tapping.

Howmet's [Keysert and Keenserts catalog](https://www.howmet.com/wp-content/uploads/sites/3/2023/05/Keysert_and_Keenserts_Catalog.pdf), PDF p. 4, supplies 16 inch thin-wall/heavy-duty 1/4–1/2 internal-thread records in the library. Each stores the carbon part number, internal and external thread pair, length, regular Unified tap drill, countersink diameter and minimum tap depth. A Keensert uses a **regular Unified class 2B tap matching its external thread**. A Heli-Coil parent hole uses an **STI tap** sized for a wire insert. Neither tap nor its drill recommendation is interchangeable. The directly tapped case also uses a regular Unified tap; its pilot drill is left unspecified because the selected class and process are not known.

Thread material picks use `mechanics-core::materials::builtin_catalog`, including 4340 steel, 17-4 PH H1025 CRES, 15-7 Mo PH CRES, Ti-6Al-4V Grade 5, 7075-T6, 2024-T3 and 7050-T7451. The chosen record supplies bolt Ftu/Fsu, parent Fsu and, for a solid insert, insert Fsu. Values are material data, not certified fastener or insert product ratings. A manual strength edit drops that member's catalog link. Older cases without material IDs retain their entered strengths. The Heli-Coil 304 stainless cold-worked wire tensile range is listed in the [manufacturer catalog](https://www.stanleyengineeredfastening.com/-/media/web/sef/resources/docs/heli-coil/heli-coil_catalog_hc2000_rev12.pdf); it does not provide a matching assembly shear/pull-out rating. The Workbench does not turn that wire tensile range into a capacity.

The bolt, parent and Keensert insert material rows open the searchable Material Lookup catalog; the picker shows matching conditions and Ftu/Fsu instead of fixed material buttons. The damage characteristic row opens a dropdown of all changes valid for the selected thread family. Inputs and Results docks can each minimize to an edge tab, restore, and retain that state when switching dashboard tabs. The boxed workbench toolbar uses one row, leaving more height for the assembly.

[Stanley HC68-2](https://www.stanleyengineeredfastening.com/-/media/web/sef/resources/docs/heli-coil/tensile_strength_hc68-2_rev4.pdf) publishes room-temperature assembly tensile strength against parent ultimate shear strength and nominal coil length. Its inch charts occupy PDF pp. 4–35 (2-56 through 1-14); this is the source to expand the numerical screen size by size. The 1/4-20 and 1/4-28 charts (PDF pp. 15–16) are digitized as approximate 1D and 1.5D trend lines. The Workbench shows a downward-rounded 100 lbf chart estimate when parent Fsu is 15–50 ksi, effective engagement is 1–1.5D, and the plotted strength stays within the chart's vertical range. Lengths between 1D and 1.5D are interpolated for a damage comparison. This row is advisory and cannot become the governing assembly rating; matching product, installed length, parent condition, STI geometry and qualification still require confirmation. HC68-2 itself calls the plotted parent strengths average room-temperature values and directs unplotted sizes/lengths to its application engineers.

[NASA RP-1228](https://ntrs.nasa.gov/api/citations/19900009424/downloads/19900009424.pdf), printed p. 21, gives `P = π d_m F_s L / 3` for a **directly tapped hole**. It is not a Heli-Coil assembly equation: its empirical one-third factor assumes ordinary mating threads, while HC68-2 measures a wire-insert assembly. Do not substitute it for the manufacturer's chart. [DLA lists NASM8846](https://quicksearch.dla.mil/qsDocDetails.aspx?ident_number=203581) as the active helical-coil procurement document and [NASM33537](https://quicksearch.dla.mil/qsDocDetails.aspx?ident_number=211815) as active inch standard assembly dimensions. Public DLA pages expose adoption notices, not the standard tables, so no unverified NASM pull-out values or STI major limits were copied into the library. The [Stanley HC-2000 catalog](https://usgage.com/wp-content/uploads/2023/08/Heli-Coil_Catalog_HC2000_Rev12.pdf), PDF p. 7, remains the source for the modeled STI hole limits. NASM122076–NASM124850 and NASM21209 identify insert products, not a general parent-material pull-out equation.

Further inch-only expansion sources: [Heli-Coil Bulletin 2003](https://www.helicoil.in/pdf/HeliCoil%20Catalogue.pdf) PDF pp. 16, 20–21 has drill depths, STI tap styles, classes and dimensions; [Noblefix professional kits](http://www.noblefix.com/PDF/Helicoil/HeliCoil-Professional-Kit.pdf) has inch kit contents, insert and STI-tap part numbers; [Camloc Keenserts](https://hfsindustrial.com/pub/media/resources/images/image/e/-/e-camloc_keenserts_complete_03_2023.pdf) PDF pp. 20–30 has inch miniature/heavy series; [Howmet](https://www.howmet.com/wp-content/uploads/sites/3/2023/05/Keysert_and_Keenserts_Catalog.pdf) PDF pp. 4, 7 has thin-wall, heavy and extra-heavy installation/removal dimensions; [Northeast Aerospace](https://www.northeastaero.com/pdf/northeast-aerospace-keensert-catalog.pdf) PDF pp. 14, 16 has miniature/heavy installation dimensions, modified minor diameters and shear engagement data. Future UI can expose tap style and depth, countersink, insert length/part number, removal drill and class/UNJ selection after a row is verified against its rendered table. Those dimensions alone do not establish assembly strength.

## Offline FEA surrogate assessment

The Thread Workbench currently uses analytical Unified thread areas and sourced catalog data. Its rendered assembly is illustrative, not an FE mesh. `fastened-joint-solver::thread_load_distribution` already solves a linear coupled-spring load distribution for a conventional bolt/nut; it does not predict stripping, wire-insert pull-out, key cracks or plastic collapse. `fea-core` has 3D contact and plasticity, but this workbench has no thread-specific conforming contact mesh, damage law or failure calibration.

An offline FE surrogate is feasible as an **advisory, versioned model** after representative physical pull-out tests validate the FE model. A useful inch-only pilot is 1/4-20 and 1/4-28 tapped and Heli-Coil assemblies at 1D and 1.5D engagement, matching the published HC68-2 charts. Model measured external/internal diameters, material condition, insert specification, pitch-to-diameter ratio, engagement-to-diameter ratio, wall-to-diameter ratio, material stiffness and yield-to-modulus ratios, friction and installation state. A Keensert pilot additionally needs its actual external thread, key geometry and parent edge/wall geometry. These are not all inputs in `Case` today.

For each FE case, retain geometry, mesh convergence, constitutive law, contact/friction assumptions, boundary conditions, load-displacement history, failure criterion and source test. Validate failure mode and load against held-out physical assemblies and held-out thread sizes/material conditions. Do not treat an FE peak stress or first yield as pull-out capacity. An independent product of `K_load × K_wall × K_damage` is only justified after factorial interaction checks; cracks, wall yielding and damaged threads can change the governing mode. Prefer a small bounded interpolation table with an explicit applicability envelope and uncertainty before curve fitting or machine learning. Outside that envelope, show no surrogate estimate. Manufacturer qualification and design allowables remain separate from the advisory estimate.

The first practical increment is to add measured damage descriptors and parent wall geometry, then calibrate one tapped size against physical tests. Expand to coil and keyed inserts only after their installed geometry and failure paths are validated. No FEA correction factor is applied to current capacity rows.

The first input increment records minimum radial parent wall thickness in inches (from the outermost parent thread root to the nearest free surface) and offers fully ineffective entry turns for a directly tapped hole. The latter removes an integer number of pitches from the analytical effective engagement, so its two thread-stripping rows scale with the remaining length. This is an idealized geometric screen, not a contact or local failure prediction. The wall measurement is saved and reported but does not change capacity. Existing cases load with wall unspecified. No FE dataset or physical pull-out validation is present, so the surrogate still produces no estimate.

Next offline pilot: 1/4-28 directly tapped assemblies at `L_e/D = 1.0, 1.5`, minimum radial `t_wall/D = 0.5, 1.0`, and 0, 1 or 2 fully ineffective entry turns. This is 12 physical configurations, each requiring at least three mesh levels. Record complete stress-strain curves, the contact/friction model, installation condition, displacement-controlled force history, failure definition and observed mode. Compare against independent pull-out tests; reserve 1/4-20 and at least one different parent condition as hold-outs. Published chart trends can guide checks but are not a substitute for matching physical validation. Do not fit or ship coefficients from an unvalidated matrix.

An inch-series external validation reference is [NASA/ATK Thiokol's damaged parent-hole insert study](https://ntrs.nasa.gov/api/citations/20050180634/downloads/20050180634.pdf). It tested helical inserts in 7075-T7351 parent stock with 15 engaged threads and a restrained pristine mean of 59,768 lbf in Table 2 (rounded to 59,760 lbf and 3,984 lbf per thread in the paper's equations); local pitch-diameter deviations were about 0.003 or 0.005 in radially. An axisymmetric elastoplastic contact FE model informed its equivalent-missing-thread method. The authors observed reductions up to three equivalent threads from combined general enlargement and local damage in their particular hardware. Their result is not a universal three-thread deduction or a coefficient for the 1/4-28 tapped pilot. It also shows why measured pitch-diameter *profile*, parent ductility and insert rolling matter beyond one effective diameter. Reproduce this study's trend only as a separate coil benchmark after matching its specimen geometry and installation restraint; obtain independent cases before fitting a transferable model. [Transcribed Tables 2 and 3](thread-workbench-nasa-coil-validation.md) preserve the source values and flag a B2/B3 equivalent-thread inconsistency.

The Thread Workbench's **Evidence tables** action opens an offline HTML view of those 18 NASA series. It plots the two table means, keeps published values immutable, and lets users edit specimen values in a separate working copy. Edits save in the shared app-data folder as `thread-evidence.json`, independent of a case and available after reopening the app; concurrent windows reject a stale save instead of overwriting another window. The browser view and its edits do not change strength rows or calibrate an FE surrogate. Future documentation tables and plots referenced for this workbench are to be digitized into the same evidence-view feature set, with source values and editable working values kept distinct.

The damage/change comparison starts from an exact copy of the baseline case. It changes only the selected property: changing an internal minor diameter does not change major or pitch diameters, TPI, material, load or the fixed Unified 60-degree thread angle. Changing TPI or nominal major in the comparison also leaves measured diameters alone. Editing the baseline nominal size or TPI is a different operation: it regenerates the basic Unified dimensions for the new baseline definition.

[NASA's threaded-insert strength treatment](https://ntrs.nasa.gov/api/citations/19960012183/downloads/19960012183.pdf), pp. 22–24, reduces key-locked insert external shear area for the area interrupted by keys, and conservatively uses that reduced area for parent threads. Its tables are calculated allowables for identified MS51830/MS51831 configurations, not pull-out tests or generic Keensert factors. The Workbench's unadjusted Keensert external and parent thread areas are therefore displayed only as **gross-area upper bounds** and excluded from governing capacity; a matched full-assembly rating remains necessary. A future keyed-insert model needs the actual key geometry or a sourced net engagement area for the selected part.
