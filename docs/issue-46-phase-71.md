# Issue 46 — Phase 71: registry v3 (strategy generation, verdict table, evidence matrix) and one-call shell preparation (#54/#64, #52/#53)

Stacked on Phase 70.

**Registry v3** (`fea_core::meshing::compatibility`): `candidates(template)` generates one request per known strategy in the audited order (`STRATEGIES`); `explain(candidates, budget)` returns every strategy's verdict, so a `select` answer always comes with why each other option was rejected; `EVIDENCE` is the matrix of what each available strategy is certified for, the committed document holding its numbers and the first registry version in which the claim holds; `is_available` states which strategies exist at all. Verdicts of `check` did not change; `REGISTRY_VERSION` is 3. A test fails if an available strategy has no evidence entry, if an unavailable one has, or if a cited document is missing from the tree.

**`solid_kernel::shell_prepare::prepare_shell`**: weld (Phase 70) then flat-patch cleanup (Phase 69) in one call that cannot fail (a refusing stage is skipped with a note; a result with a smaller smallest-shell-angle than the input is discarded and the input returned). The cleanup tolerances are widened to twice the longest welded edge relative to the bounding box, because the weld may have moved geometry by that much and the planes it leaves are only that flat; without this a welded corner 2e-6 off its walls blocked every neighbouring dissolve (found by the test, fixed). `step-inventory --clean-shell` now uses it (one code path instead of two copies).

Evidence (macOS arm64): 3 registry tests (generated candidates cover every strategy; the verdict table for a Tet10 solid is lattice-only and for Tet4 plus a 30-degree shell is lattice then native; evidence completeness and document existence) and 3 preparation tests (a 4x4x1 gridded box with a seam needle, smallest angle 0.0058 degrees, prepares to a shell of at most 9 vertices and more than 14 degrees; an open shell is returned unchanged with two notes; a healthy box is returned as it is). Sampled bracket shell (example only): unchanged at 0.0123 degrees, as in Phase 70.

Limits: the evidence matrix records where the numbers are, not that they are re-run; the registry still ranks by audited order, with cost-based ranking left to `meshing::cost`; no sliver-face defeaturing yet, so the sampled bracket remains `ShellAngleTooSmall`; no Windows or hosted-CI evidence.
