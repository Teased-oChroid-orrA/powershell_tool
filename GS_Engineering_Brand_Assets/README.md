# GS Engineering icon package

Approved turbine G + blue aerodynamic S, adapted from the supplied banner.

- Windows: multi-resolution `windows/GS_Engineering.ico` (16–256 px).
- macOS: `macos/GS_Engineering.icns`, plus an editable `.iconset` (16–1024 px).
- PNG: 30 square sizes, 16–2048 px, with genuine transparency.
- Web: favicon, Apple touch icon, PWA icons, maskable icons, manifest and HTML snippet.
- Linux: hicolor application icons.
- Master: high-resolution transparent PNG; see manifest for native dimensions.
- Preview: light/dark backgrounds and actual small sizes.

Use ICO for Windows executables/shortcuts and ICNS for macOS app bundles. Icons do not install themselves; rebuild or configure your application with the appropriate file. Place the web folder assets at the path used by the HTML snippet; adjust names and manifest settings for your application.

All sizes derive from one consistent raster master. Very small sizes retain the silhouette but cannot retain full turbine detail. This package contains raster artwork, not editable vector artwork. Enhanced full banner and slim headers are included. The original banner is included for reference. Higher-resolution artwork was regenerated with the built-in image-generation tool; exports are raster PNG, not vectors. See generation-notes.json for prompts and native dimensions.
